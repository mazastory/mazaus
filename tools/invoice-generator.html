글로벌 상업송장(Commercial Invoice) 작성 가이드 및 필수 규정

상업송장(Commercial Invoice)은 단순한 대금 청구서가 아닌, 수출입 통관 시 세관(Customs Border Protection)이 관세와 부가세를 산정하는 가장 핵심적인 법적 공문서입니다. 필수 정보 누락 시 통관 지연 및 과태료가 발생할 수 있습니다.

1. 세관 통관을 통과하는 5대 필수 기재 요소

  • 명확한 품명 (Precise Goods Description): 단순히 'Sample'이나 'Merchandise'라고 표기하면 100% 보류됩니다. 구체적인 재질과 용도(예: 'Specialty Ceramic Dripper for Coffee Brewing')를 명시해야 합니다.
  • HS Code (통번 분류 기호): 전 세계 공통 6자리 HS Code(Harmonized System Code)를 기재하여 관세율이 올바르게 적용되도록 지원합니다.
  • Incoterms 2020 인도조건: 운임과 보험료를 누가 부담하는지(FOB, CIF, DDP)를 표기하여 과세가격 산정의 기준을 제공합니다.
  • 원산지 증명 (Country of Origin): 생산 제조국(예: Republic of Korea)을 각 품목별로 명확히 표시합니다.

2. 인보이스 종류: Proforma vs Commercial

견적 송장(Proforma Invoice)은 계약 전 바이어에게 발송하는 사전 견적용이며, 상업 송장(Commercial Invoice)은 실제 화물이 선적되어 세관 신고 및 정식 결제가 이뤄질 때 발행하는 최종 법적 증빙입니다.

영문 인보이스 생성기 사용법

수출입 거래나 해외 고객에게 보내는 영문 인보이스를 만드는 도구입니다. 품목, 수량, 단가를 입력하면 품목별 합계가 계산되고, 운임과 보험료를 더한 총액이 만들어집니다. 인쇄하거나 PDF로 저장할 수 있습니다. 입력한 내용은 서버로 전송되지 않습니다.

품목 합계 = 수량 × 단가

소계 = 모든 품목 합계의 합

총액 = 소계 + 운임(Freight) + 보험료(Insurance)

계산 예시

품목 하나가 10개 × $25.00 = $250.00이고 운임이 $40.00, 보험료가 $10.00이라면 소계는 $250.00, 총액은 $300.00입니다.

알아 두면 좋은 점

  • HS 코드 칸은 직접 입력하는 자리입니다. 어떤 코드를 써야 하는지는 이 도구가 판단하지 않으니, 관세사나 해당 국가의 세관 안내를 확인하세요.
  • 이 도구는 인보이스의 서식을 만들어 줄 뿐이며, 통관에 필요한 서류의 요건을 보장하지 않습니다. 운송사와 도착 국가의 요구 사항을 확인하세요.
  • 세금(부가세, 관세)은 계산하지 않습니다.
